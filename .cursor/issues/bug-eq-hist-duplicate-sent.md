## Опис

Після першого send в історії одиниці один рядок «Відправлено». Після редагування видачі (edit send з version) з’являється другий такий самий рядок замість оновлення існуючого.

Очікувана поведінка: REQ-EQU-004 AC-04.

**Корінь (бекенд):** слухач `EquipmentHistoryService.onEquipmentSent` з умовою `#event.getEquipment().status == IN_TRANSIT` знову пише SENT при edit send, бо статус обладнання не змінюється.

## Steps to Reproduce

1. Авторизуватися під роллю Owner 1.
2. Обрати склад відправника.
3. Створити обладнання і передати на інший склад.
4. Відкрити діалог одиниці на `/equipment` — переконатися, що «Відправлено» одне.
5. Перейти в «Видати/Отримати» → «В дорозі» → редагувати видачу (змінити «Примітки») → «Підтвердити».
6. Знову відкрити діалог одиниці → секція «Історія».

## Expected Result

Не більше одного рядка «Відправлено» для цього переміщення; при edit оновлюється існуючий запис або його атрибути.

## Actual Result

У «Історія» два (або більше) рядки «Відправлено» для одного переміщення.
