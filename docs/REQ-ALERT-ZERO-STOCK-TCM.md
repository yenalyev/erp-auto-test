## Нульовий залишок ресурсу зі сповіщенням

На сторінці «Залишки» ресурс із фактичним залишком `0` відображається, якщо для нього на вибраній локації налаштовано сповіщення по залишках, навіть коли тогл «Показувати нульові залишки» вимкнений. Рядок показує `0`, бейдж «відсутній» і налаштований поріг. Нульовий ресурс без такого сповіщення при вимкненому тоглі прихований; при ввімкненому тоглі обидва видимі. Після видалення сповіщення нульовий ресурс знову прихований за вимкненого тогла. Ненульові ресурси лишаються видимими.

Hierarchy API `GET /api/v1/storages/inventory?parentStorageId=...&showZeroStock=false` має повертати нульовий ресурс зі сповіщенням і виключати нульовий ресурс без нього. При `showZeroStock=true` повертаються обидва. Правило стосується таблиці `/inventory`; контракт Excel-експорту і «Скопіювати» визначений окремо в REQ-WMS-007.

Новий критерій: `AC-06`. Автоматизовані кейси: `TC-ALERT-006` (API), `TC-UI-ALERT-005` (UI). Запланована регресія: `TC-UI-ALERT-006` (сповіщення тільки в іншій локації), `TC-UI-ALERT-007` (пошук, пагінація та зміна залишку). Існуючий `TC-UI-ALERT-003` перевіряє типи локацій із увімкненим тоглом і не замінює перевірку вимкненого тогла.
