## Підтверджено

- Кнопка експорту доступна на сторінці статистики та завантажує валідний XLSX.
- Workbook містить п'ять видимих предметних аркушів у правильному порядку.
- Дані виготовлення, витрат виготовлення, розбору, витрат розбору та несерійних
  витрат потрапляють до відповідних аркушів без змішування.
- Активний внутрішній таб не змінює склад workbook.
- Верхні фільтри періоду, локації, категорії та виробу передаються в export request
  і впливають на результат.
- `rawResources=true` застосовується для «Лише матеріали»; локальний пошук у таблиці
  не входить до контракту багатолистового експорту.
- Порожня вибірка повертає п'ять аркушів із заголовками.
- Числові значення записані як numeric cells.
- Запит до недоступної локації повертає `403` без даних.
- Після контрольованої відповіді `500` UI показує помилку, а повторний експорт без
  reload успішний.
