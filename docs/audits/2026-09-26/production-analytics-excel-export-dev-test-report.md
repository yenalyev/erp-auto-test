# DEV test report — Production Analytics Excel export

Дата: **2026-09-26**
Середовище: **DEV**
Обсяг: `/analytics/production` → «Статистика» → «Експорт в Excel»

## Підсумок

Функціональний acceptance contract `TC-ANL-UI-013…028` повністю автоматизовано.
Тести компілюються. Feature на DEV не пройшла acceptance: автоматизація виявила
п'ять продуктових невідповідностей.

Підтверджені успішні перевірки:

- валідний XLSX, точні п'ять видимих аркушів і їхній порядок;
- погоджені заголовки кожного аркуша;
- незалежність workbook від активного внутрішнього таба;
- включні межі періоду та відсутність записів поза ним;
- location scope, multiselect `OR`, комбінація верхніх фільтрів `AND`;
- скидання фільтра без залишкового `resourceIds`;
- валідний порожній workbook;
- повний набір із 25 унікальних контрольних записів без обрізання пагінацією;
- numeric cell types;
- `403` для чужої локації та `401/403` для користувача без дозволу;
- помилка UI на контрольований `500`, retry без reload та ізоляція послідовних
  експортів `L1`/`L2`.

## Виявлені дефекти DEV

1. `TC-ANL-UI-017` — `Виготовлення - Витрати`: для контрольного матеріалу в
   `Обсяг` експортовано `1`, очікувана фактична витрата `16.5`.
2. `TC-ANL-UI-019` — `Розбір - Витрати`: експортовано `1`, очікувано `2`.
3. `TC-ANL-UI-020` — `Несерійне виробництво - Витрати`: експортовано `2`,
   очікувана агрегована витрата `14`.
4. `TC-ANL-UI-022` — при multiselect «Вироби» workbook містить обидва готові
   вироби, але не містить пов'язаних з ними ресурсів витрат.
5. `TC-ANL-UI-023` — та сама помилка відтворюється для перетину
   `Локація + Категорія + Виріб`.

Перші три дефекти порушують `AC-EXCEL-05`; два останні — `AC-EXCEL-04` та
`AC-EXCEL-05`.

