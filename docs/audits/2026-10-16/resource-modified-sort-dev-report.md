## Результат

Фікс підтверджено на dev: **3 PASS, 0 FAIL, 0 SKIP**, без помилок setup і cleanup.

- `TC-RES-SORT-API-001`: загальний каталог, ASC і DESC, точні ID та `updatedAt`.
- `TC-RES-SORT-API-002`: каталог обмеженої локації, ASC і DESC, три сторінки
  з `size=1`, пошук, порожня вибірка та повернення до сортування за назвою.
- `TC-RES-SORT-UI-001`: реальні кліки «Змінено», запити ASC/DESC і скидання,
  правильний `storageId`, точний порядок рядків, відображення дат у часовому
  поясі браузера, відсутність HTTP 5xx у запитах списку ресурсів.

Три контрольні ресурси створено в порядку C, B, A; після цього змінено C.
Фактичний порядок дат B, A, C відрізняється від порядку назв і створення.
Мітки перевірено з повною точністю API, хоча UI показує лише хвилини.

Повна компіляція Maven на Java 21 успішна; остаточні зміни фікстури та UI-тесту
скомпільовано через javac на тому самому classpath. Перевірка реєстрації
класів у `regression.xml` — **1 PASS**. `git diff --check` для змінених
tracked-файлів задачі пройшов.
