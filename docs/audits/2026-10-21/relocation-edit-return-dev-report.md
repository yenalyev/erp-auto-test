## Очищення

Власні ресурсні видачі видаляються перед отриманнями, запаси очищаються, ресурси й локації архівуються, категорії видаляються. Власне обладнання переведено в RETIRED із перевіркою серверного статусу. Незмінна внутрішня історія й історія обладнання залишаються з неактивними товарами та заархівованими локаціями; ID додано до Allure.

Залишки перерваного прогону також очищено після відновлення dev: [маніфест CLEANED](relocation-edit-return-pending-cleanup.json), [звіт відновлення SUCCESS](relocation-edit-return-recovery.json). Активних залишків і локацій цього набору немає. API відхилив видалення частини історії обладнання; відповідні ID та відповіді API зафіксовано у звіті відновлення, обладнання виведено з обігу.
