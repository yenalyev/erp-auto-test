- Поєднані фільтри локацій, дат, категорії, двох виробів та постачальника зберігаються на обох вкладках. Підтверджено реальні PUT, видимі поля й рядки, query журналу та повторний Excel.

## Що заблоковано

- Для «Отримано» спостерігач помилково обрав пізню відповідь GET із прихованої вкладки «В дорозі». Видима вкладка й поля відповідали знімку. Спостерігач виправлено: запити історії вибираються за states. Після цього потрібен повтор кейса 005.
- Нічна перерва перервала мережу. Наступні виконання отримали ERR_NETWORK_CHANGED, ERR_CONNECTION_REFUSED або timeout. 22.10.2026 доступ до dev:443 окремо перевірено — з’єднання відхиляється.
- Кейси одного виробу, повторного знімка та обладнання не мають надійного остаточного результату. Час виконань, які перетнули перерву, містить час простою й не є оцінкою продуктивності.
