## TC-UI-EQ-002 — регресія стандартного створення

ACTIVE, існуючий кейс REQ-EQU-002 / AC-02. EquipmentCreateUITest#createSeveralEquipmentInOneRelocation.

На власній дочірній локації заповнити дві одиниці з унікальними назвами, категорією, постачальником і без серійних номерів. Розгорнути/згорнути підказку другої картки, натиснути «Зберегти всі 2».
