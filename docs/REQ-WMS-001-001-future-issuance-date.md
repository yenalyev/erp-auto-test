# REQ-WMS-001-001 — Заборона видачі майбутньою датою

TCM: дочірня вимога `REQ-WMS-001` («Операція Видати»). Статус у dev TCM — `IN_PROGRESS`.

## Правило

При створенні видачі та при зміні її дати під час редагування дата не може бути пізніше поточної календарної дати системи. Верхня межа однакова для бізнес-власника, комірника й адміністратора. Це стосується видачі ресурсів та обладнання, зокрема форм видачі на локацію, екіпаж і між точками вильоту.

Сервер має повернути HTTP 400 з помилкою поля `date`. Невдалий запит не створює переміщення і не змінює дату, вміст, статус чи залишки існуючої видачі. UI також має не дозволяти вибрати та надіслати майбутню дату, але серверна перевірка потрібна для прямих API-запитів.

Це **верхня** межа. Вимога `REQ-EDIT_REL / AC-08` (CPMA-796) задає **нижню** межу для неадміністратора: дата не раніше вчорашньої. Адміністратор звільнений від нижньої межі, але не від верхньої.

## Критерії та автотести

| AC dev TCM | Перевірка | Наявні API-тести |
|------------|-----------|------------------|
| AC-01 | Створення видачі завтрашньою датою відхилене для неадміністратора й адміністратора; залишок незмінний | `TC-REL-DATE-010`, `011` |
| AC-02 | Зміна дати існуючої видачі на завтра відхилена для неадміністратора й адміністратора; запис та залишок незмінні | `TC-REL-DATE-012`, `013` |
| AC-03 | Форми видачі блокують майбутню дату | Окремого UI-автотесту наразі немає |

Усі чотири API-сценарії знаходяться в `RelocationOneDayLimitTest`. Вони описують очікувану поведінку, а не підтверджують поточну реалізацію.

## Стан реалізації на 14.09.2026

У `tk-ui` форми видачі встановлюють HTML `max` для поля дати. У `tk` метод `RelocationValidator.validateDate` відхиляє порожню дату та дату раніше дозволеної нижньої межі, але не перевіряє дату після сьогодні. Тому прямий API-запит з майбутньою датою поки проходить валідацію дати; `TC-REL-DATE-010…013` залишаються червоними. Вимогу не слід позначати виконаною до серверної перевірки й повторного запуску цих тестів.

Запуск: `mvn test -Denv=dev -Dtest=RelocationOneDayLimitTest`.
