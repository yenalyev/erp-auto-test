## Доступ і склад сторінки

Користувач із правом Resource Viewer бачить пункт «Відстеження ресурсів». Сторінка містить фільтри, журнал, блок «Сумарно переміщено» та Excel-експорт.

## Category-only пошук

Коли вибрано категорію і не вибрано окремих ресурсів, перемикач «Групувати по нижніх компонентах» доступний і за замовчуванням увімкнений. Увімкнений стан залишає найнижчі пов'язані компоненти, вимкнений — найвищі. Згорнуті рівні позначаються «Згруповано», а деталі беруться з groupedFrom. Одне фізичне переміщення показується один раз.

## Явно вибрані ресурси

Після явного вибору хоча б одного ресурсу перемикач category-only групування недоступний. Якщо вибрані готовий виріб і його напівфабрикат, UI показує обидві декомпозиції та обидва підсумки без маркера «Згруповано».

## Узгодженість

UI не перераховує склад самостійно: таблиця, підсумки та groupedFrom відповідають API. Excel використовує поточні фільтри й режим групування.

## Фільтр «Батальйони»

На сторінці `/resources-viewer/relocation` поле «Батальйони» відкриває список доступних батальйонів ПМ. Список з'являється після кліку по полю; у ньому не має бути дублікатів. Вимога називає поле «Отримувач - батальйон», тому остаточний підпис треба узгодити окремо.

Вибір батальйону вимикає поле «Отримувачі» та чекбокси «ПМ 414», «СБС без ПМ 414», «Інші». Раніше вибрані групи не мають звужувати пошук за батальйоном. Вибір конкретного отримувача, навпаки, вимикає поле батальйону. Кнопка «Очистити» прибирає обидва типи вибору й знову активує всі фільтри отримувачів.

Для пошуку за батальйоном журнал, підсумки та Excel-експорт мають містити лише відповідні переміщення. Зміна батальйону має оновлювати результат, а відсутність переміщень — давати порожній результат без сторонніх записів.

Автоматизовані UI-кейси `TC-UI-RVW-006–009` перевіряють наявність списку, взаємне блокування фільтрів і очищення. Вони використовують динамічно створену глобальну роль Resource Viewer. На dev 30.09.2026 увесь `ResourceViewerUiTest` пройшов: 9/9, без пропусків. Повноту списку відносно довідника ПМ, точність журналу, підсумків та експорту за батальйоном ці автотести не доводять; для цього залишаються ручні `TC-UI-RVW-010–013`. Прогону цих кейсів на prod не зафіксовано.
