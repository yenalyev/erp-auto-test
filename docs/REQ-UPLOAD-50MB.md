# Завантаження файлів

Користувач може додати файли до проєктного виробництва та фото до ресурсу. Система приймає допустимі файли, зберігає їх без зміни вмісту й дає відкрити пізніше.

## Обмеження розміру

- Для проєктного виробництва діє ліміт 50 МБ на кожен файл і на всі файли одного завантаження разом. До загального розміру входять також службові дані, тому файл із рівно 50 МБ вмісту може перевищити ліміт запиту.
- У формі ресурсу можна додати одне фото розміром до 5 МБ. Серверний ліміт 50 МБ діє також для прямого завантаження фото.
- Якщо окремий файл або весь запит завеликий, система відхиляє завантаження і не зберігає відхилені вкладення.

## Повідомлення користувачу

Форма проєктного виробництва показує повідомлення про перевищення розміру й не показує повідомлення про успішне збереження. Для допустимого файла завантаження завершується успішно, а вміст можна отримати без змін.

## Примітка для перевірки

На dev ERP 26.09.2026 перевищення повертало повідомлення «Розмір файлу перевищує допустимий 50MB.»; локальний вихідний код backend має інший, старіший текст. Критерії AC-01–AC-05 охоплюють шість кейсів TC-UPLOAD-50-01…06: малий файл, завеликий файл, повідомлення у формі, фото ресурсу та сумарний розмір кількох файлів. Набір пройшов на dev 26.09.2026 (6/6); запуск на production ERP цим не підтверджено. Детальні технічні кроки зберігаються в `docs/FILE_UPLOAD_50MB_TEST_CASES.md`.
