# TC-PLAN-ANL-UI-003 — Підсумки аналітики плану за одиницями вимірювання

**Сторінка:** `/analytics/plan` → «Аналітика» → «Для плану»

**Пріоритет:** високий

**Мета:** перевірити, що загальні показники не додають кілограми до штук або інших несумісних одиниць.

## Передумови

- Користувач має доступ до аналітики плану.
- За вибраний період є два ресурси в області видимості користувача з різними одиницями вимірювання. У порядку «Вироблено», «Відвантажено», «Використано», «Залишок усього», «Залишок (Цукрарня)» контрольні значення такі:
  - A (кг): `10`, `4`, `2`, `7`, `3`.
  - B (шт): `5`, `1`, `3`, `8`, `6`.

- Значення отримані з тестових операцій або контрольованої відповіді API. Фактичні величини можуть відрізнятися; важливо, щоб обидві одиниці мали ненульові значення для кожного показника.

## Кроки

1. Відкрити `/analytics/plan` і встановити період, за який підготовлено дані.
2. У фільтрі ресурсів вибрати **одночасно** A та B.
3. Перевірити загальні підсумки «Вироблено», «Відвантажено», «Використано», «Залишок усього», «Залишок (Цукрарня)».
4. Звірити рядки таблиці з одиницями вимірювання та значеннями для кожного ресурсу.
5. Залишити у фільтрі лише A, потім лише B; після кожного вибору повторно перевірити підсумки.

## Очікуваний результат

- Для кожного з п'яти показників значення **розділені за одиницею вимірювання**. Для A показано відповідно `10 кг`, `4 кг`, `2 кг`, `7 кг`, `3 кг`; для B — `5 шт`, `1 шт`, `3 шт`, `8 шт`, `6 шт`.
- Жоден підсумок не показує змішану суму без одиниці: `15` для «Вироблено», `5` для «Відвантажено», `5` для «Використано», `15` для «Залишок усього» або `9` для «Залишок (Цукрарня)».
- У таблиці кожен рядок зберігає власну одиницю; підсумки не залежать від порядку вибору ресурсів.
- При виборі одного ресурсу залишається тільки його одиниця та відповідні значення; підсумки оновлюються без залишків від попереднього вибору.

**Додатково:** повторити перевірку для вибору категорії, яка містить ресурси з різними одиницями. Якщо відображено кілька сторінок таблиці, підсумки мають відповідати всьому поточному фільтру, а не лише видимій сторінці.

## Автоматизація

`PlanAnalyticsUiTest` (`TC-PLAN-ANL-UI-003`) підставляє контрольовані рядки й перевіряє окремі величини в усіх п'яти UI-підсумках. `PlanAnalyticApiTest` (`TC-PLAN-ANL-004`) звіряє кожну групу `totals` із сумою рядків лише відповідної одиниці. Контракт API описаний у `plan-analytic-page-schema.json`: `totals` — масив об'єктів з полем `unit`.
