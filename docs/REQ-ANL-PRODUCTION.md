# REQ-ANL-PRODUCTION — аналітика виробництва

Статус: **автоматизовано; dev 2026-09-25 — 7/8 passed, виявлено Excel-дефект**
Сторінка: `/analytics/production`
Актор: **Керівник локації**
Батьківська вимога TCM: `REQ-ANL`

## 1. Обсяг вимог

### AC-01 — доступ і тестові дані

- Керівник локації має доступ до сторінки аналітики виробництва.
- Аналітика обмежена доступною актору локацією.
- Автотести створюють окремі локацію, користувача, ресурси, зміну та записи виробництва.
- Shared-користувачі та shared-локації, зокрема `OWNER_1`, у сценаріях не використовуються.
- Створені дані очищаються після тестового класу.

### AC-02 — вкладка «Поденне»

- Доступні фільтри «Період», «Локації», «Категорії» та «Вироби».
- «Обсяг за період» і `amount` timeline збігаються з `amount` відповідного запису журналу виробництва.
- Задіяний персонал і `staffCount` timeline збігаються з `workerQty` snapshot-зміни у записі журналу.
- Пресети «1 день» і «7 днів» встановлюють очікуваний календарний діапазон.
- Помилка завантаження не відображається.

### AC-03 — фільтрація «Поденне»

- Вибір виробу передає його ID у `resourceIds` timeline-запиту.
- Вибір категорії передає її ID у `categoryIds`.
- Вибір локації передає її ID у `storageIds`.
- Фільтри комбінуються, не змінюючи правильні обсяг і кількість персоналу для відфільтрованого запису.
- Батьківський scope запиту відповідає динамічно створеній локації керівника.

### AC-04 — сума витрат несерійного виробництва

- Для одного матеріалу витрати кількох записів несерійного виробництва агрегуються як сума `production amount × usage per unit`.
- Для даних `2 × 3` та `4 × 2` API і UI показують загальну витрату `14`.
- Агрегація містить дві операції та один рядок матеріалу.
- Запит `/production/analytic/non-serial/input` обмежений динамічно створеною локацією.

### AC-05 — вкладка «Статистика» та Excel

- Перемикаються представлення «За категоріями», «За тегами», «За виробами», «Витрати» та «Продуктивність».
- Перемикаються типи «Виготовлення», «Розбір» та «Несерійне виробництво».
- Після вибору «Несерійне виробництво → Витрати» відображається рядок створеного матеріалу.
- «Експорт в Excel» повертає непорожній файл із коректною XLSX/OOXML сигнатурою.
- Workbook відкривається парсером і містить матеріал поточного відфільтрованого набору.

### AC-06 — чекбокс «Лише матеріали» і підказка

- У представленні «Витрати» біля пошуку для «Виготовлення», «Розбору» та «Несерійного виробництва» видимий чекбокс «Лише матеріали».
- За замовчуванням чекбокс вимкнений; після перезавантаження сторінки відновлюється вимкнений стан.
- Біля чекбокса є `InfoIcon`; наведення або keyboard focus показує текст: «Матеріали — ресурси які не виготовляються і не мають активних техкарт».
- Стан чекбокса зберігається при перемиканні між трьома типами виробництва.

### AC-07 — глобальна фільтрація матеріалів

- При вимкненому чекбоксі зберігається попередня повна вибірка витрат.
- При активному чекбоксі UI передає `rawResources=true` для витрат «Виготовлення», «Розбору» та «Несерійного виробництва».
- Матеріалом вважається ресурс, який глобально не має жодної активної техкарти будь-якого типу.
- Активна техкарта іншої локації також виключає ресурс із вибірки.
- Ресурс без техкарт або лише з неактивними техкартами залишається у вибірці; наявність хоча б однієї активної техкарти виключає ресурс.
- Фільтр комбінується з періодом, локаціями, категоріями, вибраними ресурсами та пошуком за назвою; summary і таблиця обчислюються за відфільтрованими рядками.

### AC-08 — Excel враховує фільтри витрат

- `GET /production/analytic/export` отримує `rawResources=true`, коли активний чекбокс «Лише матеріали».
- Excel враховує тип виробництва, період, локації, категорії, вибрані ресурси і текст «Пошук за назвою…».
- Workbook містить повну відфільтровану вибірку, а не лише видиму сторінку таблиці.
- При активному фільтрі workbook містить матеріали згідно з пошуком і не містить ресурсів з активними техкартами.

## 2. Тест-кейси

### TC-ANL-UI-005 — пресети періоду

Передумови: створено динамічну локацію та користувача з роллю «Керівник локації».

1. Відкрити `/analytics/production` і picker «Період» — доступні всі стандартні пресети.
2. Вибрати «1 день» — `from` і `to` дорівнюють поточній даті браузера.
3. Вибрати «7 днів» — `from = today - 7`, `to = today`; текст trigger змінився.

### TC-ANL-UI-006 — обсяг і персонал із журналу

Передумови: створено production journal record з `amount=6` та snapshot-зміною `workerQty=7`.

1. Відкрити вкладку «Поденне» динамічним керівником — сторінка і фільтри доступні без помилки.
2. Прочитати створений запис журналу та timeline — `timeline.amount = journal.amount`, `timeline.staffCount = journal.shift.workerQty`.
3. Звірити картки UI — «Обсяг за період» дорівнює `6`, персонал дорівнює `7`.

### TC-ANL-UI-007 — регресія суми витрат

Передумови: створено один матеріал і два записи несерійного виробництва з витратами `2 × 3` та `4 × 2`.

1. Відкрити «Статистика → Витрати → Несерійне виробництво» — запит scoped до динамічної локації.
2. Перевірити API — `count=2`, `operations=2`, `totalAmount=14`.
3. Перевірити UI — підсумковий обсяг і значення рядка матеріалу дорівнюють `14`.

### TC-ANL-UI-008 — фільтри вкладки «Поденне»

Передумови: створено виробництво з відомими product/category/location та snapshot-зміною.

1. Вибрати «Вироби» — timeline URL містить product ID; обсяг і персонал відповідають журналу.
2. Вибрати «Категорії» — URL містить category ID; значення не змінюються помилково.
3. Вибрати «Локації» — URL містить storage ID; scope і значення відповідають тестовим даним.

### TC-ANL-UI-009 — таби статистики та Excel

Передумови: створено серійне й несерійне виробництво на динамічній локації.

1. Послідовно відкрити всі п’ять представлень статистики — кожен вибраний таб стає активним.
2. Перемкнути «Виготовлення», «Розбір», «Несерійне виробництво» — відповідний тип стає активним.
3. Вибрати «Несерійне виробництво → Витрати» — видно динамічний матеріал.
4. Експортувати Excel — файл непорожній, має XLSX signature, парситься і містить поточний матеріал.

### TC-ANL-UI-010 — чекбокс і tooltip матеріалів

1. Відкрити «Статистика → Витрати» для кожного з трьох типів виробництва.
2. Перевірити наявність «Лише матеріали» та вимкнений початковий стан.
3. Навести курсор на `InfoIcon` — видимий погоджений текст підказки.

### TC-ANL-UI-011 — глобальна семантика та збереження фільтра

Передумови: створено три витратні ресурси — без техкарти, лише з неактивною техкартою та з активною техкартою іншої локації.

1. Увімкнути «Лише матеріали» для «Виготовлення» — input-запит містить `rawResources=true`.
2. Перемкнутися на «Розбір» і «Несерійне виробництво» — чекбокс лишається активним, кожен input-запит містить `rawResources=true`.
3. Перевірити non-series response — перші два ресурси є, ресурсу з активною техкартою немає.
4. Вимкнути чекбокс — `rawResources` не передається, ресурс з активною техкартою повертається.

### TC-ANL-UI-012 — Excel враховує «Лише матеріали» і пошук

1. Відкрити «Несерійне виробництво → Витрати» і ввімкнути «Лише матеріали».
2. У «Пошук за назвою…» ввести назву одного матеріалу — UI показує лише його.
3. Експортувати Excel — URL містить `rawResources=true`.
4. Розпарсити workbook — пошуковий матеріал є, іншого матеріалу та ресурсу з активною техкартою немає.
