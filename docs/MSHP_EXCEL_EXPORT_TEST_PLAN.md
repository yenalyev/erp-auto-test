# Списання МШП — експорт в Excel

Вимога `REQ-MSHP-EXCEL`, дочірня до `REQ-MSHP`. Джерело: запит користувача 28.10.2026. ERP: dev, `https://dev.cukerochka.sbs`, backend `/server`.

## Контракт і ризики

Експорт запускається реальною кнопкою на `/inventory/low-value-write-offs`. Файл має відображати ту саму вибірку, що й історія, з усіх сторінок. Перевіряються значення операцій, ресурсів та дробових кількостей. Розгорнутий dev повертає один рядок на ресурс операції та колонки «Дата», «Локація», «Ресурс», «Кількість», «Од. вимір», «Створив», «Коментар». Порядок колонок та назва файлу не обмежуються. Кількість перевіряється як число Excel; порівнюється точний мультимножинний склад рядків, включно з кількома ресурсами операції. Порожню вибірку перевіряємо як книгу із заголовками без даних.

Експорт є читанням: не змінює спільних залишків, номерів чи резервів; окремий race-сценарій не потрібен. Незмінність створених операцій і залишків перевіряється повторним GET. Перевірки конкурентного списання належать окремій функціональності.

Локальний frontend `LowValueWriteOffListPage.tsx` і backend `InventoryLowValueResourceController` на початку роботи не містять експорту. Розгорнутий dev відрізняється: фактично підтверджено кнопку та GET `/api/v1/storages/inventory/low-value-resources/export`. Фільтри: parentStorageId, storageIds, categoryIds, resourceName, fromDate, toDate; без page/size. Додано прямий API-контроль відмови без write-off.read; Бухгалтер перевіряється реальним UI-завантаженням.

## Критерії приймання

- **AC-01:** На сторінці історії списань МШП доступна кнопка експорту. Натискання завантажує валідний XLSX із повними даними вибірки, включно з ресурсами, точними дробовими кількостями, локацією, датою, автором і коментарем; експорт не змінює операцій чи залишків.
- **AC-02:** Excel використовує всі активні фільтри сторінки: назву ресурсу, категорії, multiselect локацій (OR), період з включними межами та їх перетин (AND). Зміна й скидання фільтрів застосовуються до наступного файлу; порожня вибірка не повертає попередні або сторонні записи.
- **AC-03:** Експорт включає всю відфільтровану вибірку незалежно від поточної сторінки таблиці; без втрат і дублів. Область локацій та права на читання історії застосовуються також до експорту; користувач без права не має доступу.

## Автоматизовані сценарії

### TC-MSHP-XLSX-UI-001 — Завантаження Excel та точний вміст без зміни даних [AC-01]

Автотест: `LowValueWriteOffExportUiTest#exportsCurrentHistory`.

1. Відкрити історію у власній локації; експортувати; прочитати книгу та повторно GET операції й залишки.

Очікування: Валідний XLSX містить усі власні операції, точні ресурси/кількості/автора/дату/коментар; контрольна локація виключена; стан незмінний.

### TC-MSHP-XLSX-UI-002 — Пошук ресурсу переноситься до Excel [AC-02]

Автотест: `LowValueWriteOffExportUiTest#exportsResourceSearch`.

1. Через UI знайти cloth, експортувати; змінити пошук на gloves та експортувати повторно.

Очікування: Кожен файл містить лише операції відповідного пошуку; попередня вибірка не кешується.

### TC-MSHP-XLSX-UI-003 — Категорії та локації застосовуються до Excel [AC-02]

Автотест: `LowValueWriteOffExportUiTest#exportsCategoriesAndLocations`.

1. У просторі всіх локацій вибрати створену категорію та A; експортувати; додати B, експортувати; вибрати контрольну категорію.

Очікування: Категорія фільтрує операції; A виключає B, A+B включає обидві; контрольна категорія дає порожню вибірку.

### TC-MSHP-XLSX-UI-004 — Період із включними межами та день без записів [AC-02]

Автотест: `LowValueWriteOffExportUiTest#exportsPeriod`.

1. Обрати сьогодні–сьогодні через календар, експортувати; обрати вчора–вчора та повторити.

Очікування: Сьогодні включає власні записи на межах; вчора не включає сьогоднішні операції.

### TC-MSHP-XLSX-UI-005 — Перетин та скидання фільтрів [AC-02]

Автотест: `LowValueWriteOffExportUiTest#exportsCombinedAndResetFilters`.

1. Задати ресурс cloth, категорію, A та сьогодні; експортувати; натиснути Скинути фільтри та експортувати.

Очікування: Перший файл має лише перетин; після скидання файл повертає повну власну вибірку з урахуванням workspace.

### TC-MSHP-XLSX-UI-006 — Порожня вибірка не експортує сторонні записи [AC-02]

Автотест: `LowValueWriteOffExportUiTest#exportsEmptySearch`.

1. У власній локації ввести унікальний відсутній ресурс та експортувати.

Очікування: Валідний XLSX із заголовками без рядків даних; немає попередніх чи сторонніх записів.

### TC-MSHP-XLSX-UI-007 — Excel із другої сторінки містить усю вибірку [AC-03]

Автотест: `LowValueWriteOffExportUiTest#exportsAllPages`.

1. Створити 26 власних операцій; перейти на другу сторінку size=25 та експортувати.

Очікування: Файл містить точно всі 26 операцій без дублів; контрольна локація виключена.

### TC-MSHP-XLSX-UI-008 — Доступ Бухгалтера й заборона користувачу без права [AC-03]

Автотест: `LowValueWriteOffExportUiTest#enforcesHistoryReadPermission`.

1. Увійти окремими динамічними акторами: Бухгалтер та без права читання; відкрити історію; перевірити API читання та UI експорту.

Очікування: Бухгалтер завантажує дозволену вибірку; без права — API 403, маршрут 403, кнопка експорту відсутня.

## Ізоляція та запуск

ADMIN створює динамічні A/B/external, власні ресурси та категорії. Бухгалтер і актор без права створюються динамічно. Cleanup видаляє власні списання/надходження, архівує локації та ресурси з перевіркою GET, деактивує акторів і видаляє власні категорії. Manifest зберігається у каталозі прогону. Suite `low-value-write-off-export`, також `ui` і `regression`; перевірки framework — окремим запуском. TCM production/local синхронізуються зі збереженням історії.

Суміжна регресія в suite: TC-MSHP-API-007 (фільтри/пагінація), TC-MSHP-API-008 (RBAC), TC-MSHP-UI-010 (UI-фільтри). 26 операцій з однією багаторесурсною операцією дають 27 рядків Excel.
