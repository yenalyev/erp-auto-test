# Залишки: Excel-аркуш «По складах»

Коли користувач експортує залишки в Excel, книга містить аркуші «Залишок» і «По складах». Новий аркуш допомагає побачити загальний залишок ресурсу, його бронювання та кількість на кожному вибраному складі.

## Що бачить користувач

Перші колонки аркуша «По складах» ідуть у порядку: «Назва», «Залишок», «Заброньовано», «Одиниця Виміру», «Категорія». Далі йде окрема колонка з назвою кожного складу, який має ресурс у поточній вибірці. Склади впорядковані за назвою. Якщо вибраний склад після фільтрів не має ресурсів, його колонка прихована. Якщо певного ресурсу немає на складі, який має інші ресурси, його складська комірка порожня.

Ресурс має один рядок для всієї вибірки. «Залишок» показує суму кількостей на вибраних складах, «Заброньовано» — суму броні. Колонка складу показує його власну кількість. Кількості записані як числа Excel, зокрема для дробових значень.

## Вибірка

Експорт враховує вибраний склад разом із дочірніми складами або перелік вибраних локацій, пошук, категорію, теги та перемикач нульових залишків. Ресурс із нульовим залишком включається, коли показ нулів увімкнено; за вимкненого показу його немає. До книги не потрапляють ресурси недоступних складів.

## Перевірки

- TC-WMS-007-023: завантаження книги зі сторінки «Залишки» для всіх доступних локацій.
- TC-WMS-007-028: два склади, один ресурс, правильні підсумки й складські колонки.
- TC-WMS-007-024: ієрархія складів і окремий вибір одного складу.
- TC-WMS-007-025: пошук, категорія, тег і перемикач нульових залишків.
- TC-WMS-007-026: бронювання та дробові кількості.
