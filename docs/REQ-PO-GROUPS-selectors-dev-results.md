# Перевірка селекторів виробничих груп — dev, 10.09.2026

Виконано два UI-автотести: TC-PG-031 («Видати») і TC-PG-032 («Отримати»).
Обидва завершилися FAIL через порушення AC-13. Errors: 0, Skipped: 0.
Очищення тестових даних завершене без помилок. Бекенд і фронтенд не змінені.

## Відтворення

1. Створити активну виробничу групу та допустимі звичайні локації.
   Для «Отримати» використати зовнішні локації типу UNIT: саме такі джерела допускає форма.
2. Увійти користувачем з доступом до локацій, вибрати звичайну робочу локацію.
3. Відкрити «Видати» → «Кому відправляю» або «Отримати» → «Зі складу (Джерело)».
4. Перевірити початковий список, пошук за повною та частковою назвою групи.

Очікується: виробнича група не показана в жодному з трьох варіантів.
Фактично: група показана у всіх трьох варіантах, в обох формах.

Додатково підтверджено: пошук дочірньої звичайної локації та локації поза групою працює;
звичайну локацію можна обрати. Видача й отримання не підтверджувалися, залишки не змінювалися.
